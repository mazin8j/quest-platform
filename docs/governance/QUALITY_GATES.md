# QUEST Quality Gates

## G0 — Requirement Gate
User value, acceptance criteria, out-of-scope items, success metric defined.

## G1 — Architecture Gate
Bounded context, interfaces, events, failure modes, migration impact documented.

## G2 — Security/Privacy/Safety Gate
Threats, permissions, data sensitivity, abuse cases, minors/location implications evaluated.

## G3 — Implementation Gate
Types, lint, unit/integration tests, schema migration, API contracts, telemetry complete.

## G4 — Verification Gate
QA reviews acceptance criteria and runs critical automated flows. Security/safety reviewers sign off where required.

## G5 — Release Gate
Feature flag/rollout, dashboards/alerts, rollback, migration recovery, support/moderation readiness documented.
