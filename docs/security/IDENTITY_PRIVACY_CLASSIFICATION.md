# Identity & Profiles — privacy classification (Phase 01, G2)

Applies `docs/architecture/05_DATA_ARCHITECTURE.md` classes and `docs/security/PRIVACY_PRINCIPLES.md`
to every data element the phase introduces. Purpose limitation: each element is collected for the
named purpose only; a new purpose requires review and, where required, consent.

## Principles applied (PRIVACY_PRINCIPLES.md)

1. **Purpose limitation** — inventory above; the DOB has exactly one purpose and one reader (`accountAgeBand`).
2. **Minimisation** — country is the most precise location element; `PRECISE` is not a value; devices store no hardware ids (client-generated installation id).
3. **Consent** — analytics/personalisation/marketing default to false and are never pre-ticked (`registrationConsentsSchema`); the ledger records every decision with source and version.
4. **Transparency & control** — `/me/privacy`, `/me/blocks`, `/me/sessions`, `/me/devices`, `/me/consents`, deactivate, delete, export.
5. **Location** — only country at profile level; `locationVisibility` caps what later phases may show.
6. **Blocked users** — `BlockQueryPort` exported for the social graph; profile reads already enforce precedence.
7. **Minors** — band-based defaults and hard limits (`AGE_BAND_PRIVACY_POLICY`); adults-only public/discoverable for 13–15.
8. **User rights** — export contract (`DataExportContributor` per context, bundle schema in `@quest/types`) and deletion cascade (`AccountDeletionJob` + `identity.account.deleted`).
9. **Cross-border** — no data leaves the region: mail delivery adapter selection is a release-gate decision (TD-21); OIDC verification fetches only public keys.

## Events and analytics

- `identity.account.*` and `profiles.profile.updated` payloads carry identifiers, band, country and language only (`packages/events/src/catalog/identity.test.ts`).
- No analytics events are emitted by Phase 01 (taxonomy arrives in Phase 15); when they are, `anonymousId` must be a pseudonym unrelated to `account.id`.

## Open privacy items

- Retention job for `identity_audit_ledger` and expired sessions (TD-26).
- Regional age-of-consent overrides and parental controls (later phase; foundation in `age-policy.ts`).
- Data-processing record for the mail provider once selected (TD-21).
